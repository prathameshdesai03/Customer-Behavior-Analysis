# Customer Behavior Analysis – SQL

## 📌 Project Overview

This project focuses on analyzing customer purchasing behavior using SQL. The analysis explores customer transactions, product categories, revenue, returns, and spending patterns to generate meaningful business insights.

- SQL
- MySQL
- Data Analysis
- Data Aggregation
- Joins
- Subqueries
- CASE Statements

## 🎯 Objectives

- Analyze customer purchasing behavior
- Identify high-value customers
- Analyze sales and revenue performance
- Examine product and category performance
- Analyze customer transactions and returns
- Generate business insights using SQL
